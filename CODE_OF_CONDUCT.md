# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**In short:** be respectful, be constructive, assume good faith. Harassment,
personal attacks, and disruptive behavior are not tolerated — in issues,
pull requests, reviews, or any other project space.

Instances of unacceptable behavior may be reported to
**steven.ceuppens@x3m.industries**. All reports are handled confidentially.
Maintainers who don't follow or enforce this code may be removed from the
project.
